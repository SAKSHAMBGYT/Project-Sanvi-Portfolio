# Project assets

Images are served in numeric order. `1` is the first piece shown.

## Add a project

1. Drop the image in this folder.
2. Name it with the next number: `14.jpg` (`.png`, `.jpeg`, `.webp` also work).
3. Refresh the site. It appears in the archive automatically.

Keep numbering unbroken ; discovery stops at the first missing number.
To reorder, renumber the files. To feature a piece in the big cinematic
scroll scenes, give it one of the first four numbers.
